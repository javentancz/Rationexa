# Changelog

Notable user-facing and architectural changes are recorded here. Rationexa is
still a supervised pilot, so releases may include breaking changes.

## [Unreleased]

- Add full-history secret scanning and scheduled staging health checks.
- Add public-preview privacy, retention, support, and BYOK guidance.

## 0.2.0 - 2026-09-07

- Added the Import, Review, Finalize, and Revisit decision-memory workflow.
- Added isolated guest trials and account-scoped persistent workspaces.
- Added encrypted workspace BYOK connections, provider tests, and explicit
  model activation.
- Added read-only expiring shares, Markdown/PDF exports, account deletion,
  password recovery, and active-session management.
- Added deterministic grounding, source offsets, provenance, usage reporting,
  golden and real-world evaluation cases, and human-gated judgments.
- Added PostgreSQL migrations, backup and restore tooling, Docker Compose,
  Vercel staging support, Vitest, Pytest, Playwright, and PostgreSQL CI.
