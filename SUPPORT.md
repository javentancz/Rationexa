# Support

Rationexa is an open-source supervised-pilot project. Community support is
best-effort; the hosted staging preview has no uptime or data-durability SLA.

## Ask for help

Before opening an issue, check the [README](README.md), existing issues, and the
[pilot operations guide](ops/README.md). If the problem remains, open a GitHub
issue using the appropriate template and include:

- the Rationexa version or commit;
- local, Docker, or hosted-staging environment;
- expected and actual behavior;
- minimal reproduction steps; and
- sanitized logs or screenshots when useful.

Never include API keys, session or reset tokens, confidential decision source
material, database dumps, or personal data in an issue.

## Security issues

Do not report vulnerabilities in a public issue. Follow the private reporting
instructions in [SECURITY.md](SECURITY.md).

## Hosted preview

The public preview is for evaluation with non-confidential material. Guest data
expires automatically, and registered staging data may be reset during ongoing
development. Self-host Rationexa when you need control over availability,
retention, infrastructure, or sensitive data.
