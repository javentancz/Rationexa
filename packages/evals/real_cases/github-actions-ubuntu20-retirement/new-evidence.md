# GitHub retired the Ubuntu 20.04 hosted runner

Evidence date: 2025-04-15

Official source:
https://github.blog/changelog/2025-01-15-github-actions-ubuntu-20-runner-image-brownout-dates-and-other-breaking-changes/

GitHub announced that the `ubuntu-20.04` hosted runner image would be fully
retired on April 15, 2025 and recommended moving workflows to Ubuntu 22.04 or
24.04. Workflows pinned to the retired label can no longer depend on that
hosted image being available.

This supersedes the availability premise and satisfies the explicit review
condition.
