# PostgreSQL remains open source and actively supported

Evidence date: 2026-08-13

Official sources:

- https://www.postgresql.org/about/licence/
- https://www.postgresql.org/support/versioning/
- https://www.postgresql.org/support/

## New evidence

The PostgreSQL Global Development Group states that PostgreSQL is released
under the PostgreSQL License, a liberal open-source license similar to BSD or
MIT. The project says it remains committed to making PostgreSQL free and open
source in perpetuity and has no plans to change the license.

The project supports each major version for five years with bug fixes and, as
needed, security fixes. PostgreSQL 18 is currently supported through November
14, 2030. PostgreSQL 18.6 and supported minor updates were released on August
13, 2026.

## Why this matters

This evidence supports the original premise that PostgreSQL is an actively
maintained open-source relational database. It does not validate every
application-specific claim about ease of learning, API implementation speed,
or suitability for storing large files.
