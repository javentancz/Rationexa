# Python 3.9 is end-of-life

Evidence date: 2025-10-31

Official source: https://devguide.python.org/versions/

The Python Developer's Guide lists Python 3.9 as end-of-life on October 31,
2025. The status definition says an end-of-life release is frozen and receives
no further changes. Supported production services should migrate to a
maintained Python branch.

This evidence directly triggers the planned runtime review and contradicts the
assumption that Python 3.9 will continue receiving upstream security fixes.
