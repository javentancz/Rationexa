# Redis licensing update
Evidence date: 2024-03-20
Sources: https://redis.io/blog/redis-adopts-dual-source-available-licensing/ and https://redis.io/legal/licenses/

Redis 7.4 moved from BSD-3-Clause to RSALv2 or SSPLv1. Redis states that neither license is OSI-approved; Redis 8 later added AGPLv3 as an additional option.
