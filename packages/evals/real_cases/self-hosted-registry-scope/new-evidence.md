# Docker Hub pull limits

Evidence date: 2026-04-01

Official source: https://docs.docker.com/docker-hub/usage/pulls/

Docker Hub limits unauthenticated and Personal-account pulls during a six-hour
window. Paid plans have different limits.

This policy concerns pulls from Docker Hub. It provides no evidence about the
capacity, availability, or network location of the project's self-hosted
registry. The model should therefore produce no premise relationship.
