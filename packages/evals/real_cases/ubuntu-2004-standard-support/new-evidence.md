# Ubuntu support update
Evidence date: 2025-05-31
Source: https://ubuntu.com/blog/ubuntu-20-04-lts-end-of-life-standard-support-is-coming-to-an-end-heres-how-to-prepare

Ubuntu 20.04 reached the end of standard support on May 31, 2025. Canonical recommends upgrading or obtaining Ubuntu Pro for Expanded Security Maintenance.
