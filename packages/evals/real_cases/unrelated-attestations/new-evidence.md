# GitHub Artifact Attestations became generally available

Evidence date: 2024-06-25

Official source:
https://github.blog/changelog/2024-06-25-artifact-attestations-is-generally-available/

GitHub announced general availability of Artifact Attestations, which create
and verify signed provenance for artifacts built in GitHub Actions. The feature
is powered by Sigstore and can be used in software supply-chain policies.
